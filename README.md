# Core-MCP-Middleware

Промежуточное программное обеспечение (Middleware) на базе протокола MCP (Model Context Protocol) для интеграции LLM-агентов с платформой «1С:Предприятие».

## 🎯 Назначение проекта
Проект представляет собой интеграционный шлюз, обеспечивающий безопасный контролируемый доступ больших языковых моделей (LLM) к метаданным и бизнес-логике конфигураций «1С:Предприятие». 

> ⚠️ **Важное ограничение:** Прямые SQL-запросы к СУБД 1С строго запрещены. Взаимодействие с платформой осуществляется исключительно через изолированные HTTP-сервисы 1С с авторизацией на стороне Middleware.

## 🛠️ Стек технологий шлюза
* **Язык разработки:** Python 3.10+
* **Интеграционный протокол:** Model Context Protocol (MCP) / JSON-RPC 2.0
* **Транспортный уровень:** HTTP / WebSockets (TLS) для связи с 1С
* **Валидация данных:** JSON Schema / `demjson3`
* **Автоматизация и CI/CD:** GitHub Actions

## 🏗️ Структура репозитория
* `architecture.md` — Детальное описание схемы взаимодействия компонентов системы (Пользователь -> LLM -> MCP Middleware -> 1С) и алгоритм решения аппаратной проблемы передачи UUID (Little-Endian vs Big-Endian).
* `json_rpc_spec.md` — Техническая спецификация протокола обмена данными по стандарту JSON-RPC 2.0 для методов `Auth`, `GetMetadata` и `ExecuteTool`.
* `schemas/` — Директория с JSON-схемами для автоматической валидации структуры запросов.
* `.github/workflows/main.yml` — Скрипт автоматизации (GitHub Actions), запускающий проверку синтаксиса и выводящий статус сборки документации.
